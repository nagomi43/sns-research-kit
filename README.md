# SNSリサーチ Muse テンプレート

Instagram / Threads の「バズっている投稿」と「伸びている競合アカウント」を調べて、自分のアカウントの診断と「次に何をすべきか」まで出してくれるリサーチアプリを、**自分の Muse で動かすための設計パッケージ（雛形）**です。YouTube 分析ツール vidIQ の「Meta版」をイメージしています。

これは完成品のソフトウェアではなく、**設計書と実行プロトコルのセット**です。受け取った人が自分の Muse に読み込ませてセットアップすると、その人の環境に、その人専用のアプリが立ち上がります。

## 仕組み（重要）

このアプリは、Meta の公式 API を直接叩く普通の Web サービスではありません。3つの部分でできています。

1. **アプリ画面（表）** — 検索条件の入力、結果の閲覧、自分の属性登録、診断レポートの表示を行う画面。Muse のアーティファクト（データ保存ができる Web アプリ）として動きます。
2. **Muse（裏のエンジン）** — アプリに登録されたリクエストを受け取り、実際に Instagram / Threads のデータを取得し、バズ度や診断スコアを計算して、結果をアプリに書き戻します。
3. **データの蓄積** — 検索のたびにデータセットが保存され、同じジャンルの2回目以降は蓄積分を再利用して速く・広くなります。

つまり「検索エンジンは自分の Muse」です。だからこそ、Meta の開発者審査なしに、自分のアカウント連携の範囲で今日から動かせます。

## できること

- **バズ発見（さがす）** — キーワードで検索し、投稿を「そのアカウントの普段の平均の何倍の反応か（相対バズ度）」で並べ替えて表示。投稿詳細では公式埋め込みで動画を再生し、「なぜ伸びたか」の分解も添えます。
- **自分の診断** — カテゴリ別スコア（プロフィール／発信量／反応の質／バズ再現性／テーマの幅）＋根拠となる実数と競合の中央値＋「次の一手」上位3つ。Instagram と Threads を切り替えて診断できます。
- **アカウント・競合ウォッチ** — 気になるアカウントを登録すると、フォロワー数・直近20件の平均／中央値・投稿頻度・最大バズ度・バズ投稿トップ3・頻出テーマが自動で分析され、自分の数字と比較できます。
- **キーワード・テーマ研究** — キーワードを入れると関連テーマを広げて調べ、テーマごとの集まり具合・平均反応・強いアカウントと「伸び筋／競合が強い／穴場候補」の所見が返ります。

## 前提条件

- **Muse が使えること**（このパッケージは Muse の利用者を対象にしています）
- **自分の Muse に Instagram / Threads のコネクタがあること** — リサーチ担当の Muse が、あなたの連携済みアカウント経由で公開データを読み取ります。コネクタがない環境ではリサーチは動きません
- 調べられるのは**公開アカウントのみ**です。パスワードは扱いません（自分のアカウントは @ID の入力だけで特定します）

## 使い方の全体像

1. このフォルダを自分の Muse に渡して、 `SETUP.md` の指示文でアプリを構築してもらう
2. アプリができたら「自分の診断」タブで自分の @ID・タイプ・ジャンルなどを登録する
3. 「さがす」タブでキーワードを検索すると、裏で Muse がリサーチを開始し、数分後に結果が入る
4. 競合ウォッチとキーワード研究も同じ方式（ボタンを押す → 裏で Muse が調査 → 結果が保存される）
5. 起動に失敗したリクエストは、毎時の保険チェックが拾って処理する

新しいキーワードの初回検索は、Muse が実際にデータを取りに行くため**数秒では返りません**。「リサーチ中」と正直に表示され、完了したら知らせる設計です。

## 注意事項（必ず読んでください）

- **位置づけ**: これは個人が自分の責任で使う、学習・研究用の雛形です。動作保証もサポートもありません。
- **取得できないデータがあります**: 他人の投稿の再生数・リーチ・保存数・シェア数は公開データに存在しないため取得できません。このアプリの指標は、いいね・コメント・フォロワー数などの公開データだけから計算しています。
- **Meta の規約について**: データ取得は、ログイン済みアカウント経由の読み取りに依存します。これは Meta の利用規約上グレーな面を含む方法です。個人利用の範囲を超えた配布・商用利用はリスクが変わります。使うかどうか、どの範囲で使うかは、各自の判断と責任でお願いします。
- **レート制限**: 短時間に大量の取得を行うと、プラットフォーム側のレート制限（429等）に当たります。プロトコルには「制限に当たったらそのプラットフォームは停止し、取得済み分で結果を出す」ルールが含まれています。節度ある利用を前提としてください。
- **数字の読み方**: 検索結果の「件数」は検索サンプル内の数であり、プラットフォーム全体の総数ではありません。診断スコアは公開データに基づく目安です。
- **自動投稿はしません**: このアプリは読み取り専用です。投稿・フォロー・いいね等の書き込み操作は行いません。
